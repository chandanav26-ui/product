College Notes Sharing Portal — project summary

Full-Stack Project

College Notes
Sharing Portal

A secure, full-stack web application where students upload, search, and download peer notes — organized by subject, semester, and department.

MongoDB Express.js React.js Node.js JWT Auth Multer bcrypt REST API

Authentication & security

JWT tokens — stateless session management for secure login/logout flows
bcrypt password hashing — salted encryption protecting user credentials at rest
Protected routes — middleware-guarded API endpoints requiring valid token headers
Registration & login — full user lifecycle with input validation and error handling

File management

Multer integration — multipart/form-data middleware handling PDF uploads on the server
Metadata tagging — notes stored with subject, semester, and department for structured retrieval
Download endpoint — streaming PDF delivery via RESTful routes with access control

Search & discovery

Filter notes by subject, semester, and department — compound query support via MongoDB
Responsive note cards listing uploader, date, and file size at a glance
One-click download directly from search results — no extra navigation steps
